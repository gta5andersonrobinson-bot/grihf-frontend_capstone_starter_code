# StayHealthy - Medical Appointment Booking Platform

## Project Overview
StayHealthy is a front-end web application developed as part of a Front-End Development Capstone Project. It is a digital platform for a fictitious non-profit healthcare organization aimed at improving access to medical services. The application allows users to register, log in, search for doctors by specialty, book medical appointments, leave reviews, and manage their user profiles.

## Features Built
*   **User Authentication:** Dynamic Sign-Up and Login forms.
*   **Doctor Search & Booking:** Search interface to find specialists and a dynamic form to book appointments (date, time, doctor details).
*   **Profile Management:** User profile card with editing capabilities for personal details.
*   **Notifications:** Application-wide alerts for successful bookings or actions.
*   **Reviews System:** Ability for users to submit feedback for completed consultations.

## Prerequisites
Before you begin, ensure you have the following installed on your machine:
*   [Node.js](https://nodejs.org/) (which includes npm)
*   Git

## Setup and Installation Instructions

**1. Clone the repository**
Open your terminal and clone the project to your local machine:
\`\`\`bash
git clone https://github.com/YOUR_USERNAME/stayhealthy-capstone.git
\`\`\`

**2. Navigate to the project directory**
\`\`\`bash
cd stayhealthy-capstone
\`\`\`

**3. Install Dependencies**
Install all required Node modules and React dependencies:
\`\`\`bash
npm install
\`\`\`

## Running the Application

**Development Mode**
To run the app in the development environment, execute:
\`\`\`bash
npm start
\`\`\`
This will automatically open the application in your default web browser at `http://localhost:3000`. The page will reload if you make edits to the code.

**Production Build**
To build the app for production to the `build` folder, execute:
\`\`\`bash
npm run build
\`\`\`
This correctly bundles React in production mode and optimizes the build for the best performance.
